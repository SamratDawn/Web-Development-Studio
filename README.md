# Web Development Studio

A small collection of HTML, CSS, and JavaScript projects for practicing frontend fundamentals.

## Projects

- `CineScope Search` - searches movie streaming availability by service, country, and keyword
- `TaskFlow` - a simple task list app with add, edit, save, and delete actions
- `Weatherify` - searches weather data by coordinates or browser geolocation

## Run

Each project has its own files and README. Open the project folder and follow its run instructions.
